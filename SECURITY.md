# Security policy

IPO Lab is an educational research project and does not ask users for brokerage credentials, trading passwords, payment details or personal financial account information.

## Reporting a vulnerability

Do not publish exploit details, private information or credentials in a public issue. Use GitHub's private vulnerability reporting / security advisory feature if enabled for this repository. Otherwise, contact the repository maintainer privately through the GitHub profile before sharing technical details.

## Scope

Report issues involving cross-site scripting, unsafe external links, exposed credentials, malicious data files, dependency or workflow compromise, and unintended collection or disclosure of user data.

This project does not currently provide user accounts or a server-side database.
