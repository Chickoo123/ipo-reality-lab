# A–K delivery plan

The application covers the full A–K product map. Live issuer-level research data remains a separate, evidence-gated workstream.

| Phase | Scope | Exit gate |
|---|---|---|
| 0 | Competitor checks, current regulatory rule, source access and data permissions | No unsupported uniqueness claim; source access route documented |
| 1 / MVP | B1, B2, K1, K2; 10 IPOs; C5, C6, C21, C24, P0-a/b/c; D1 | Verified RHP baseline and quarterly evidence for selected IPOs; tests pass |
| 2 | K3, K4; coverage to 25 IPOs; B3 | Seller WACA and document diffs reconcile to primary documents |
| 3 | P1 Academy, D2, D3, D6 and case library | Source-reviewed lessons, quizzes and labelled simulators |
| 4 | P2 Academy, F, D4, D5, G, B4 historical, A tracker | Legal review and data-quality checks complete |
| 5 | Claude / ChatGPT / Gemini review, accessibility and launch | Data, browser, accessibility and policy checks pass |
